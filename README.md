# 📑 Atividades e Exercícios de XML — Repositório Lima

Este diretório contém os exercícios, desafios e atividades práticas focados em **XML (Extensible Markup Language)** e suas tecnologias correlatas.

---

## 📌 Conteúdo do Diretório

A pasta `/atividades` reúne arquivos de prática para estruturação, validação e manipulação de dados em XML.

### 🛠️ Tópicos Praticados
- **Estruturação de Dados em XML:** Criação de elementos, atributos, hierarquias e formatação adequada (*Well-Formed XML*).
- **Entidades e Caracteres Especiais:** Tratamento correto de caracteres reservados (como `&amp;`, `&lt;`, `&gt;`).
- **Validação e Regras:** Aplicação de regras de sintaxe e organização lógica de documentos.

---

## 🛠️ Ferramentas Utilizadas

- **Linguagem de Marcação:** XML
- **Validadores / Editores:** VS Code (com extensões XML), Parsers XML
